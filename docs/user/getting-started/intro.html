🖥️ TresorOne

A cross-platform client for the Tresor LLM gateway. TresorOne gives you a dedicated desktop and mobile app for managing providers, aliases, rules, plugins, logs, and settings — without ever opening a terminal or a browser tab.

At a Glance​

TresorOne is the admin front-end for Tresor, the single-binary LLM gateway. Two pieces in one workflow:

ComponentWhat It Does
Tresor gateway🖥️ Long-running service that receives LLM requests, routes them to the right provider, and returns the response
TresorOne📱 Cross-platform app that connects to the gateway over the network to manage everything

│     TresorOne    │ ─────▶ │   Tresor gateway │ ─────▶ │  LLM Providers │
│       (app)      │  admin  │   (the service)  │ proxy  │  OpenAI,       │
│                  │ ◀───── │                  │ ◀───── │  Anthropic…    │

🤔 Why TresorOne?​

  • 💻 A real native client — installs as a first-class desktop or mobile app, not a browser tab
  • 🪟 Cross-platform — Windows, macOS, Linux, iOS, and Android
  • 🚀 Two connection modes — one-click Local Mode (downloads the gateway, configures it, and connects) or Remote Mode (point at any Tresor gateway by host:port + password)
  • 🧩 Familiar editor patterns — master-detail panes, swipe-to-delete chips, drag-and-drop alias reordering, tabs in forms, inline-editable text fields
  • 📺 Live log inspector — real-time viewer with Parsed + Raw tabs for captured request/response payloads
  • 🎨 Polished UI — light / dark / pure-black themes, color palette picker, and adjustable text size

Note: TresorOne does not host or proxy LLM requests itself. All traffic is routed through the Tresor gateway — TresorOne is purely a management client.

✨ Core Features​

  • 🔌 Provider management — add, edit, and remove LLM provider endpoints with an inline-editable detail pane, swipe-to-delete models, fetch-models dialog, and API format multi-select (OpenAI / OpenAI Responses / Anthropic / Gemini)
  • 🏷️ Aliases with hot-switching — model routing rules grouped by input model, with regex support, announced-name editor, drag-and-drop reorder, and one-tap activation
  • 📏 Rules & plugin pipelines — define request transformation pipelines by chaining built-in plugins; full table view with enable/disable toggles
  • 📺 Real-time log stream — live viewer with level/method/status badges, free-text filter, pause/clear, auto-scroll, and a payload inspector with a Parsed view for system / tools / messages content blocks
  • ⚙️ Settings & theme — proxy mode, log level, payload capture, retry-on-empty, admin password, proxy API keys, theme mode + palette + text size, and desktop-specific launch preferences (auto-launch, silent launch, system tray)
  • 💾 Persistence — saved connections are remembered across sessions; theme, palette, text size, and default tab persist locally
  • 🪟 System tray on desktop — minimize to tray, left-click restore, context menu (Show / Exit), and auto-reconnect on window focus

🔄 How a Typical Workflow Looks​

  1. 🚀 Launch TresorOne — pick Local Mode on a fresh install for a one-click setup, or Remote Mode if you already have a Tresor gateway running on another machine
  2. 🔌 Add a provider — fill in name, base URL, API key, pick the API format(s), and (optionally) hit Fetch Models to discover the upstream's catalog
  3. 🏷️ Define aliases — map the model names your apps send (e.g. gpt-4o) to whatever model you want behind them (e.g. claude-sonnet-5); use a regex alias to catch whole model families
  4. 📏 Configure rules (optional) — chain plugins to transform request headers or bodies before they hit the provider
  5. 📺 Watch logs — see every request come in, what provider it landed on, how long it took, and click any row to inspect the captured raw payload
  6. ⚙️ Tweak settings — adjust proxy mode, payload capture, theme, or admin password from the Settings page
