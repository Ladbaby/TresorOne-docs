🧭 Dashboard

The Dashboard is the home for every connected session. Each section keeps its place when you switch tabs, and the layout adapts to the screen size.

📐 Responsive Layout​

TresorOne ships three layouts in one widget tree, chosen at runtime by the screen size:

Size BucketShell
DesktopPersistent sidebar on the left with nav items + mode toggle footer, content on the right
TabletCollapsible sidebar with hamburger toggle, app bar title + connection indicator
MobileBottom navigation bar (4 primary tabs: Downstreams, Aliases, Rules, Settings) + mode toggle popup in app bar
tip

The boundaries are intentionally generous — TresorOne is a desktop-first client, so the desktop layout kicks in on tablets held in landscape mode, small laptops, and most external displays. Drag the window around to see the layout flip.

🏛️ Shared Shell Elements​

Every layout shares the same three pieces:

Custom Window Title Bar​

A draggable title bar at the very top of the window on desktop builds. Lets you grab the window (drag) and shows the connected endpoint on the right (clickable to open the Remote Connect Dialog).

Connection Indicator​

A colored dot + hostname displayed in the sidebar header (desktop) or app bar (tablet/mobile):

  • 🟢 Green dot — connected and healthy
  • 🔴 Red dot — disconnected or last health-check failed
  • ⚪ Grey dot — connecting / resuming

Tapping the indicator when in Remote Mode opens the Remote Connect Dialog.

Reconnect Banner​

A banner that slides in at the top of the dashboard when the connection drops. Offers two actions:

  • 🔄 Reconnect — re-runs the connection against the saved endpoint + password
  • ✕ Dismiss — hides the banner; you can re-trigger reconnect from the sidebar

The banner auto-disappears the moment the connection comes back.

Mode Toggle​

Two buttons in the sidebar footer — Local and Remote — with the active mode highlighted. Tapping the alternate mode shows a confirmation dialog (since switching ends the active connection) and then either opens the Local Mode Progress Dialog or the Remote Connect Dialog.

🧭 Navigation​

Desktop / tablet sidebar items​

ItemPurpose
🔌 DownstreamsProvider list + detail + form
🏷️ AliasesModel routing rules
📏 RulesRequest transformation rules
📜 LogsLive log stream + payload inspector
⚙️ SettingsGlobal gateway + app settings
ℹ️ AboutVersion, build info, links

Mobile bottom nav​

The mobile navigation bar collapses the desktop sidebar into 4 primary destinations:

  • Downstreams (with the same icon)
  • Aliases
  • Rules
  • Settings

Logs, About, and the Plugins subsection of Rules are reachable through the Settings → More shortcuts on mobile.

🚪 Tab State Preservation​

Each section keeps its place when you switch tabs — scrolling position in the Log viewer doesn't reset, the selected provider stays selected across tab switches, and open form routes survive until you explicitly close them.

When you sign out or the connection drops entirely, navigation falls back to the Connect screen.

🪟 System Tray (Desktop Only)​

On Windows / macOS / Linux, minimizing the window moves it into a system tray icon:

ActionBehavior
👆 Left-click tray iconRestore window
📋 Right-click → ShowRestore window
📋 Right-click → ExitQuit TresorOne; if in Local Mode, the gateway is stopped first
🪟 Close windowHide to tray (Windows: depends on the Silent Launch option in Settings → Application)
⏰ Auto-launchTresorOne starts on login (Windows: startup task · macOS: login item · Linux: autostart entry)

Mobile builds (Android / iOS) follow the platform's normal app-lifecycle rules — there is no tray and no auto-launch toggle.

🔍 Search & Filtering Tips​

  • Downstreams — type in the search field to filter the provider list by name
  • Aliases — drag a group header up or down to reorder; collapses on tap
  • Rules — toggle a switch inline to enable/disable without opening the form
  • Logs — the filter bar at the top matches against model, path, downstream, status, error, and other fields simultaneously
