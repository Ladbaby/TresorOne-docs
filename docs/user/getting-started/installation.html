📦 Installation

TresorOne is distributed as a single app. Each GitHub Release attaches one installer per supported platform plus a Source code archive.

📥 Download a Release​

Pick the row that matches your platform from the table below and click the asset name to start the download:

PlatformAssetTypeNotes
🪟 WindowsSetup (x64)TresorOne-windows-x64-setup.exeStandard installer; places the app under %LOCALAPPDATA%\Programs\TresorOne\ and adds a Start Menu + desktop shortcut
🪟 Windows (portable)Portable (x64)TresorOne-windows-x64-portable.zipNo installer — unzip and run TresorOne.exe from anywhere; useful on machines where you can't install
🍎 macOSUniversalTresorOne-macos-universal.tar.gzSingle universal binary (Intel + Apple Silicon); extract and drag TresorOne.app into Applications
🐧 Linuxtar.gz (x64)TresorOne-linux-x64.tar.gzx86_64 tarball; extract and run the bundled TresorOne binary
🤖 Androidarm64TresorOne-android-arm64-release.apkarm64-only sideload APK. Install by opening the file on the device
🍎 iOSTestFlight (separate program)—iOS builds are not published as release assets — request TestFlight access through a GitHub issue
info

Click "… download all" → "Download as zip" in the GitHub UI to grab the Source code (zip) archive along with the platform-specific binaries, or use the checksums.txt file to verify any single asset before running it.

Picking the right download​

  • Windows users — start with the Setup installer unless you need to keep the app on a USB stick or run from a folder you fully control (corporate machines, restricted accounts); in that case use the Portable zip.
  • macOS users on Apple Silicon — the Universal tarball is the right pick regardless of architecture. Do not look for an aarch64-specific artifact; there isn't one.
  • Linux users — there is no .deb, .rpm, or .AppImage in the release. Extract the tarball anywhere on your $PATH (e.g. ~/.local/bin/) and run TresorOne.

  2. If Windows SmartScreen blocks the first launch, click More info → Run anyway
  3. The installer places the app under %LOCALAPPDATA%\Programs\TresorOne\ and creates a Start Menu shortcut. Updates install over the same directory.

  2. Double-click TresorOne.exe to launch
  3. (Optional) Pin the executable to the Start Menu or taskbar for future use
  1. Extract TresorOne-macos-universal.tar.gz — it produces a TresorOne.app bundle
  2. Drag TresorOne.app into your Applications folder
  3. The first launch may require right-click → Open to bypass the unidentified developer prompt. Subsequent launches work normally.
  1. Extract the archive to a folder of your choice
  2. Make the binary executable and run it. To make it available from anywhere, put the binary in a folder on your $PATH (e.g. ~/.local/bin/)
  3. Launch from a terminal, or create a .desktop file under ~/.local/share/applications/ if you want a launcher icon
tip

On Wayland, you may need to install libgtk-3-0 and libnotify-bin if your distribution doesn't bundle them by default. Most modern distros ship both out of the box.

  1. Download TresorOne-android-arm64-release.apk from the release page
  2. Copy the APK to the device and tap to install (your device will ask you to allow installs from your file manager / browser first)
  3. Launch TresorOne from the home screen
tip

Enable Install unknown apps for the file manager or browser you sideload from. Most launchers will guide you there automatically when you open the APK.

caution

The release APK is arm64-only. x86_64 Android emulators (e.g. some Android Studio AVDs) will refuse to install it. Use an arm64 AVD image.

iOS builds are not attached to GitHub releases. To install TresorOne on iOS:

  1. Open a GitHub issue requesting TestFlight access — provide your Apple ID email so we can add you to the beta group
  2. Once accepted, install TestFlight from the App Store
  3. Accept the invitation email, then install TresorOne from inside TestFlight
  4. TestFlight builds expire after 90 days — re-install when prompted

🚀 First Run​

When you launch TresorOne for the first time, the Connect screen offers two modes:

  • 🚀 Default (Local Mode) — one-click: download the Tresor binary from GitHub Releases, auto-generate the configuration, start the gateway as a background process, and connect
  • ☁️ Advanced (Remote Connection) — enter an endpoint (http://127.0.0.1:11510) and a password to connect to any running Tresor gateway

See Connection Modes for the full walkthrough of both flows.

ℹ️ Version Info​

Open Settings → About to see:

  • 🔖 App version
  • 🛠️ Build information — Flutter SDK, framework versions
  • 🔗 Links — Tresor + TresorOne GitHub repos

🆘 Troubleshooting​

Windows SmartScreen blocks the installer​

Tip: Click More info → Run anyway. The installer is unsigned in development builds; release builds are signed before being attached to a GitHub Release.

macOS says the app is from an unidentified developer​

Tip: Right-click the .app in Finder, choose Open, then confirm in the prompt. After the first open, double-clicking works normally.

Linux: missing GTK libraries​

Tip: Install the runtime dependencies: sudo apt install libgtk-3-0 libnotify-bin (Debian/Ubuntu) or your distro's equivalent. The release tarball does not bundle GTK.

Android emulator fails with "INSTALL_FAILED_NO_MATCHING_ABIS"​

Tip: The release APK is arm64-only. Switch your AVD to an arm64-v8a system image.

App is sluggish on first launch​

Tip: TresorOne performs initialization (loading plugin metadata, etc.) on startup. Subsequent launches reuse cached state and are noticeably faster.
