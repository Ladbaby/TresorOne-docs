# ⚙️ Settings

The Settings screen is the global control plane for both the Tresor gateway (everything it forwards and how) and the TresorOne app (theme, autolaunch, default tab). Changes save automatically — no restart needed.

The mobile dashboard hides Settings in the bottom nav and exposes a **More** section containing Logs, About, and Settings instead. All the controls themselves are identical.

## 📑 Sub-Sections

| Route | What it controls |
|---|---|
| `/settings/basic-configuration` | Outbound proxy, log level, payload capture, retry-on-empty |
| `/settings/authentication` | Proxy API keys + admin password |
| `/settings/theme` | Theme mode, pure-black, color palette, text size |
| `/settings/application` | Haptic feedback, auto-launch, silent launch, default tab (desktop) |

The remainder of this page documents all four sub-sections in order.

## 🛠️ Basic Configuration

### 🌐 Outbound Proxy

A dropdown with four options. Controls how the gateway reaches downstream providers (OpenAI, Anthropic, etc.):

| Option | Behaviour |
|---|---|
| **Auto** | Try the system proxy first, then environment variables, then direct connection |
| **Environment Variables Only** | Use environment variables only — fall back to direct if unset |
| **Windows System Proxy + Env Fallback** | Same as Auto, but explicitly invokes the Windows registry on Windows builds |
| **None** | Always direct connection; ignore system + environment proxy settings |

Contextual help text below the dropdown explains each mode's behaviour. The setting saves immediately.

### 📃 Log Level

A dropdown bound to the gateway's log level:

- 🪲 **Debug** — every request + transformer step
- ℹ️ **Info** (default) — request line + outcome + duration
- ⚠️ **Warn** — only warnings and errors
- ❌ **Error only** — errors only

### 📦 Payload Capture

A toggle:

- ✅ **Enabled** — the gateway keeps the most recent request and response bodies in memory, making the [Logs inspector](logs.mdx) usable
- ❌ **Disabled** (default) — no capture; the inspector renders a "no captured payload" page for every entry

Unavailable while disconnected.

### 🔁 Retry on Empty Response

A toggle:

- ✅ **Enabled** — when the provider returns a successful response but produces no content (e.g. thinking-only reasoning), retry up to 3 times with exponential backoff. Retries are transparent to the client.
- ❌ **Disabled** (default) — pass the empty response straight back to the client

> **Tip:** Non-200 responses (4xx, 5xx) are **never** retried, regardless of this setting. Only truly empty 200s.

## 🔐 Authentication

### 🪪 Proxy API Keys

A dynamic list of text fields for proxy API keys. Each row is one token that clients must present on inbound requests.

- ➕ **Add** appends a new row
- 🗑️ Trash-can icon on each row removes it (after the save call)
- 💾 **Save** writes the whole list back to the gateway

Leave the list empty to allow all traffic through without authentication.

### 🔑 Admin Password

Two text fields (password + confirm, obscured) plus a **Change** button and an optional **Require password** checkbox:

| Action | Result |
|---|---|
| ✅ Change | The gateway starts using the new credential. TresorOne transparently re-authenticates on the next call. |
| ❌ Uncheck "Require password" + Save | Disables admin authentication entirely. Anyone with network access to the gateway can manage it. |
| ✅ Check + Save with a new password | Re-enables authentication with a fresh credential |

:::caution
Disable admin authentication only on isolated LANs. Any deployment reachable from the internet **must** keep a strong password set.
:::

## 🎨 Theme

### 🌗 Theme Mode

Three selectable cards with icons:

| Mode | Behaviour |
|---|---|
| 🌅 **Auto** | Follow the OS / browser's dark/light preference |
| ☀️ **Light** | Always light theme |
| 🌙 **Dark** | Always dark theme |

### 🖤 Pure Black Mode

A toggle that, when on, replaces every near-black surface with `#000` exactly — gives an OLED-friendly pure-black background in dark mode.

### 🎨 Theme Color

A grid of circular swatches showing primary / secondary / tertiary previews. 3 to 6 columns depending on the available width. Tap a swatch to apply it; the change is instant across the app.

### 🔠 Text Size

A slider from **0.8×** to **1.4×** with a numeric label. The change applies to the running app immediately.

## 🖥️ Application

> **Note:** All controls in this section are **desktop only**. On mobile, the entire **Application** page is hidden from Settings.

### 📳 Haptic Feedback

A toggle — when enabled, choosing controls, dragging items, and confirming destructive actions trigger a short vibration on devices with haptic hardware.

### ⏰ Auto Launch

A toggle — registers the app to start on login:

| Platform | Implementation |
|---|---|
| 🪟 **Windows** | Startup task |
| 🍎 **macOS** | Login item |
| 🐧 **Linux** | Autostart entry |

### 🤫 Silent Launch

A toggle — when on, the next launch starts hidden in the system tray. A snackbar appears after saving to explain the new behaviour ("Next start will be silent — find the app in the system tray").

### 🪟 Default Tab

A dropdown picker with options: **Downstreams**, **Aliases**, **Rules**, **Plugins** (desktop only), **Logs**, **Settings**, **About**. After a restart, the dashboard opens to the chosen tab.

## 🔁 Where Settings Are Saved

| Setting | Persisted Where |
|---|---|
| Outbound proxy mode | The gateway |
| Log level | The gateway |
| Payload capture | The gateway |
| Retry on empty | The gateway |
| Proxy API keys | The gateway |
| Admin password | The gateway + your OS's secure storage (for resume) |
| Theme mode / pure-black / palette / text size | The app |
| Haptic feedback / auto-launch / silent-launch / default tab | The app (desktop) |

:::tip
Settings that touch the gateway are applied immediately. You don't need to keep editing any file by hand.
:::
