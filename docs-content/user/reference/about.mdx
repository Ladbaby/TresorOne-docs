# ℹ️ About

The **About** screen surfaces the running app's version, the underlying tech stack, and links to the open-source projects TresorOne depends on (and the upstream Tresor project).

## 🪟 Layout

A scrollable list with the following cards (from top to bottom):

### 🟡 Brand Header

- 🟡 The app's logo
- 🟡 **Tresor One** title in the accent color
- 🏷️ Subtitle: "LLM Gateway Admin"

### 🛠️ Build Information

A card with label/value pairs:

| Label | Example |
|---|---|
| 🔖 **Version** | `1.0.0+1` |
| 🦋 **Flutter SDK** | `3.27.1` |
| 📚 **State Management** | `^2.5.0` |
| 🛣️ **Routing** | `^14.2.0` |
| 🎨 **Material Design** | `M3` |

The version string is also written to a Material badge near the logo so it's visible at a glance.

### 🔗 Links

A second card with two buttons (each opens in your default browser):

| Button | URL |
|---|---|
| 🐙 **Tresor on GitHub** | `https://github.com/ladbaby/Tresor` |
| 🐙 **TresorOne on GitHub** | `https://github.com/ladbaby/TresorOne` |

### 📜 License Footer

> Built with Flutter. TresorOne is licensed under MIT.

The full MIT license text is also bundled in the app and accessible via the About screen's footer link in some platforms.

## 🆘 Where To Get Help

- 🐛 **Bug reports** — open an issue on [TresorOne's GitHub Issues](https://github.com/ladbaby/TresorOne/issues)
- 💬 **Discussions** — the project's GitHub Discussions tab
- 🪪 **Gateway-side bugs** — open an issue on [Tresor's GitHub](https://github.com/ladbaby/Tresor/issues) instead
