# ℹ️ About

The **About** screen surfaces the running app's version, the underlying tech stack, and links to the open-source projects TresorOne depends on (and the upstream Tresor project).

## 🪟 Layout

A scrollable list with the following cards (from top to bottom):

### 🟡 Brand Header

- 🟡 **TresorOne logo** (the same `assets/images/logo_TresorOne.png` shipped with the app)
- 🟡 **Tresor One** title in the accent color
- 🏷️ Subtitle: "LLM Gateway Admin"

### 🛠️ Build Information

A `Card` with label/value pairs of monospace `SelectableText`:

| Label | Source | Example |
|---|---|---|
| 🔖 **Version** | `--dart-define=APP_VERSION` if set at build time, else `pubspec.yaml` `version` field | `1.0.0+1` |
| 🦋 **Flutter SDK** | `flutter --version` at build time | `3.27.1` |
| 📚 **State Management** | `pubspec.yaml` → `flutter_riverpod` | `^2.5.0` |
| 🛣️ **Routing** | `pubspec.yaml` → `go_router` | `^14.2.0` |
| 🎨 **Material Design** | Hard-coded `M3` constant in `core/theme.dart` | `M3` |

The version string is also written to a Material badge near the logo so it's visible at a glance.

### 🔗 Links

A second `Card` with two buttons (each opens in the system browser via `url_launcher`):

| Button | URL |
|---|---|
| 🐙 **Tresor on GitHub** | `https://github.com/ladbaby/Tresor` |
| 🐙 **TresorOne on GitHub** | `https://github.com/ladbaby/TresorOne` |

### 📜 License Footer

> Built with Flutter. TresorOne is licensed under MIT.

The full MIT license text is also bundled in the app's `LICENSE` and accessible via the About screen's footer link in some platforms.

## 🆘 Where To Get Help

- 🐛 **Bug reports** — open an issue on [TresorOne's GitHub Issues](https://github.com/ladbaby/TresorOne/issues)
- 💬 **Discussions** — the project's GitHub Discussions tab
- 🪪 **Daemon-side bugs** — open an issue on [Tresor's GitHub](https://github.com/ladbaby/Tresor/issues) instead
